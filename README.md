# 我的血壓 (My Blood Pressure PWA)

經典 Android 血壓紀錄工具《我的血壓》輕量純靜態 PWA 復刻版。  
無需安裝後端、零建置步驟（Zero-build）、完全離線可用，資料 100% 留存在使用者手機本地，保障個人健康隱私。

---

## 🌟 特色亮點

- **100% 本地隱私與持久化**：
  - 資料庫採用瀏覽器本地 `IndexedDB`，不經過任何遠端伺服器或第三方資料庫。
  - 啟動時自動申請持久化儲存權限（`navigator.storage.persist()`），防止系統在空間吃緊時清除紀錄。
- **PWA 支援（離線與桌面安裝）**：
  - 支援 Android / iOS 手機「加到主畫面」，具備獨立全螢幕 App 體驗與快取支援，無網路環境亦可完整使用。
- **經典 4 大頁籤配置**：
  1. **添加記錄**：直覺調整收縮壓、舒張壓與心率，自動帶入上次紀錄與當下時段（凌晨、上午、下午、晚上）。
  2. **歷史記錄**：依時序條列歷史量測數據與用藥/附註，點擊即可快速編輯或刪除。
  3. **統計分析**：支援每週、每月、每季、每年分組統整最低值、最高值、平均值與變化趨勢（附週次起訖日期）。
  4. **走勢圖表**：三線折線圖直觀呈現收縮壓、舒張壓與心率波動，每個數據點清楚標示數值。
- **免 Key 原生備份與分享**：
  - **匯出 / 系統分享**：支援 Web Share API，直接叫起手機系統原生分享選單，可一鍵備份至 LINE、Google 雲端硬碟或 Email。
  - **完整相容 CSV**：匯出與匯入格式完全相容原版《我的血壓》匯出的 CSV 檔案，更換手機或重裝時能一鍵還原歷史資料。

## 🚀 部署與使用方式

### 1. 部署到 GitHub Pages
本專案為純靜態網頁（Vanilla HTML / CSS / JS），不需任何打包或編譯流程：
1. 將本專案推送到 GitHub。
2. 前往儲存庫的 **Settings > Pages**。
3. 在 **Build and deployment** 下的 **Branch** 選擇 `main` 分支並選擇根目錄 `/ (root)`，點擊 **Save**。
4. 稍等數分鐘即可透過專屬網址開啟。

### 2. 安裝為手機 App (PWA)
1. 使用手機瀏覽器開啟部署好的網址：
   - **Android (Chrome)**：點擊網址列右側選單，選擇「**安裝應用程式**」或「**加到主畫面**」。
   - **iOS (Safari)**：點擊底部分享按鈕，選擇「**加入主畫面**」。
2. 回到手機桌面點擊圖示，即可像原生 App 一樣全螢幕且離線使用。

### 3. 本地端測試與預覽
若需在本機端測試，因 Service Worker 與 PWA 需要 HTTP/HTTPS 環境，可使用任意簡易 HTTP 伺服器啟動：
```bash
# 使用 Python 內建伺服器
python3 -m http.server 8080

# 或使用 Node.js 啟動
npx serve .
```
開啟瀏覽器前往 `http://localhost:8080` 即可預覽。
